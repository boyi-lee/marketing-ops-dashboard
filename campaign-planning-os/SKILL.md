# Campaign Planning OS
1. Confirm brand, period, source freshness and data definitions.
2. Set net revenue, advertising ROAS, ad spend and contribution-margin guardrails.
3. Reconcile SKU stock and historical order/discount data; never double count the same physical SKU.
4. Apply revenue drivers, ABC, Ansoff, STP/RFM and incrementality with explicit assumptions.
5. Compare multiple campaign strategies; do not write business changes without explicit approval.
6. Monitor daily actuals against original and revised targets, record evidence and maintain decision history.
Run locally: open `index.html` in a browser. Full development bundle includes Python loopback server and tests.
